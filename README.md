# Guild Site

Небольшой сайт для Discord-сервера **Гильдия**, сделанный как статический проект для публикации через **GitHub Pages**.

## О проекте

Сайт содержит:

- главную hero-секцию
- описание сервера
- правила
- список каналов
- ивенты
- staff сервера
- роли
- FAQ
- темная и светалая темы

Проект написан без фреймворков:

- `index.html`
- `guild.css`

## Структура

```text
Guild Site/
├── index.html
├── guild.css
└── README.md
```
